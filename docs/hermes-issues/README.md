# Hermes Issues

Bug reports, configuration problems, and feature requests for the Hermes AI agent system.

## Cómo contribuir

Cada issue es un archivo `.md` en esta carpeta con el formato:

```markdown
# Título descriptivo

- **Fecha**: YYYY-MM-DD
- **Reportado por**: [agente o persona]
- **Componente**: spawn_crew | kg | settings | sandbox | etc.
- **Severidad**: baja | media | alta | blocker

## Descripción

...

## Pasos para reproducir

1. ...
2. ...

## Comportamiento esperado

...

## Comportamiento actual

...

## Notas / Workaround

...
```
